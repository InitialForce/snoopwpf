# Scenario: set_property — set DatePicker SelectedDate

Set SelectedDate on a DatePicker control.

```set_property
{"locator": "//DatePicker[@Name='BirthDatePicker']", "property": "SelectedDate", "value": "2000-01-01"}
```

```get_properties
{"locator": "//DatePicker[@Name='BirthDatePicker']", "properties": ["SelectedDate"]}
```
